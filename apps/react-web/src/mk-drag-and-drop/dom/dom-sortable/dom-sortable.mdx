# DOM sortable

```ts
const controller = createDragController({
  onDragUpdate(event) {
    if (event.group !== "table-rows") return;
    projectedRows = getProjectedOrder(canonicalRows, event);
    renderVisibleRows(projectedRows);
  },
  onDragEnd(event) {
    if (event.result !== "dropped") clearProjection(event.group);
  },
  onDrop(event) {
    if (event.group === "table-rows" && event.sortablePlacement) {
      canonicalRows = applySortablePlacement(
        canonicalRows,
        event.draggableId,
        event.sortablePlacement,
      );
    }
    clearProjection(event.group);
  },
});

createSortable({
  controller,
  element: carrier,
  draggableId: row.id,
  group: "table-rows",
  containerId: "table-body",
  axis: "vertical",
});
```

`onDragUpdate` runs after package preview DOM movement and normalization. Every
normal update contains:

```ts
type SortablePreview =
  | { status: "inactive" }
  | { status: "source"; placement: SortableDropPlacement }
  | { status: "projected"; placement: SortableDropPlacement };
```

- `inactive` means the source is not a valid sortable in the captured group.
- `source` means normalized current placement equals activation-time source
  container and siblings.
- `projected` means package preview order differs, including a moved preview
  retained after leaving valid targets.

```ts
function getProjectedOrder(
  canonicalOrder: readonly string[],
  event: DragUpdateEvent,
): readonly string[] {
  if (event.sortablePreview.status === "inactive") return canonicalOrder;
  if (event.sortablePreview.status === "source") return canonicalOrder;

  return applySortablePlacement(
    canonicalOrder,
    event.draggableId,
    event.sortablePreview.placement,
  );
}
```

The application placement helper consumes normalized target/side and
previous/next anchors only. It does not recalculate targeting, midpoint,
direction, or hysteresis and does not read package-owned DOM.

Live and final placement share one normalizer. Package preview DOM is restored
before end/drop callbacks. Keep a dropped application projection until
`onDrop`, which follows `onDragEnd`; clear immediately for cancellation,
no-target, or invalid-target. A source/no-op drop omits `sortablePlacement`.

## Handles

```ts
createDragHandle({ element: menuButton });
```

The button must be a descendant of the registered sortable carrier. A quick
click remains menu activation. Once pointer drag activates, its related click
is suppressed once. Space and Enter remain button activation and do not start
keyboard drag through that interactive handle.

## Changed layout

After projected DOM or scrolling changes geometry, deduplicate a scheduled:

```ts
controller.remeasureDropTargets({ group: "table-rows" });
controller.recomputeActiveDrag();
```

Remeasurement updates cached rectangles; recompute publishes through the
ordinary preview path without implicit remeasurement.
